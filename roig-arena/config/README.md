# Directorio `config/`

Aquí se almacenan todos los archivos de configuración del framework y de paquetes de terceros.

## Archivos destacados en el contexto del Arena:
- **`database.php`**: Detalles y credenciales de las conexiones a bases de datos (MySQL).
- **`cors.php`**: Configuración de los encabezados de CORS (Cross-Origin Resource Sharing) para permitir que el frontend consuma la API.
- **`sanctum.php`**: Configuración del paquete Laravel Sanctum, encargado de emitir y validar los tokens de acceso para la autenticación de usuarios y clientes.
- **`app.php`**: Configuración general de la aplicación, como la zona horaria, configuración de idioma y variables de entorno clave.
